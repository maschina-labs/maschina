# apps

Human-facing surfaces. Things a person opens.

| App | What it is |
| --- | --- |
| `desktop` | The working environment. Electron, React, Vite. |

A docs site lands here when there is something public worth documenting, and not
before.

Nothing in here holds authority of its own. An app is a view onto the control
plane and asks it to do things; it never reaches the world directly. The desktop
app in particular keeps the human's path and the worker's path physically
separate, and that separation does not bend.
