## How to read these

Start with the primer. It is one page and it contains the entire argument in miniature. If the argument
persuades you, the whitepaper gives it in full, with the evidence attached.

After that the papers divide into three groups. The system itself is described in the architecture,
security and machine papers. What the system is for is described in the surface, network, economy and
integrity papers. What it means commercially is in the economics, path and disclosure papers.

Read the disclosures before you put money anywhere near this. They state the legal position, the
principal risks, and what nobody should assume.

## A note on the claims in these papers

Every factual claim about the outside world is cited, and the primer's citations are in the whitepaper.
These papers describe the design and make no statement about which capabilities are live at any
moment; that is published separately, dated, in the public change log. Whatever Maschina does on-chain
can be verified on-chain.

Nothing in these papers promises a financial outcome. Nothing in them ever will.
