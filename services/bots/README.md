# @maschina/bots

Chat platform integrations. Telegram first, others added here later.

A bot can alert an owner when a machine acts or pauses, send a daily summary, relay conversations with
machines and teams, and **stop**: pause every machine the owner has, immediately. Anything that would
give a machine more authority opens the web app for a wallet signature instead.

Every platform is off until its credentials are set.

```bash
pnpm bots      # port 4300
```

**Owns:** talking to people where they already are.

**Never:** touches the database or a wallet. It works through the gateway, as the owner.
