# Code of conduct

Be respectful. Disagree with ideas, not people. No harassment, discrimination or personal attacks,
in any form, anywhere this project lives.

Report problems through [GitHub's private reporting](https://github.com/maschina-labs/maschina/security/advisories/new)
or by contacting the maintainers directly. Reports are handled privately.

Maintainers may remove comments, code or contributors that break these rules.
